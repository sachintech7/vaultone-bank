How SecureVault works

1

Derive a key

Your password is stretched with PBKDF2 (150,000 rounds, random salt) into a 256-bit key.

2

Encrypt

The message is sealed with AES-GCM and a random IV, so tampering is detected on decryption.

3

Embed

Ciphertext bits replace the least significant bit of each pixel's colour channels. The image looks unchanged.

4

Extract & decrypt

The receiver reads the bits back, then decrypts with the same password to recover the exact message.

Security you can reason about

Layered protection

Encryption protects the content. Steganography hides that a message exists at all.

Reliable recovery

Encrypt and decrypt workflows verified across tested cases with 100% data recovery.

Client-side only

All processing happens locally in your browser using the Web Crypto API.
